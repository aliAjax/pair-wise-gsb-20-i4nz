# hxwl-06 视野拼接与测量校准台

玻片观察记录升级：多倍率视野校准、视野拼接整批校验、按标尺快照的测量换算、归档冻结与复核留档。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ 原生 CSS，localStorage 持久化。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106。`npm run build` 会先做类型检查再打包。

## 业务规则

- **视野登记**：每个视野必须登记物镜倍率、像素标尺（标尺像素长度）、微米值（标尺实际长度 µm）、
  载物台坐标与图像方向；三项标尺信息要么齐全，要么整体缺失。
- **拼接整批校验（原子）**：成批提交时，任一视野存在以下问题即**整批拒绝、不写入任何数据**，
  并逐视野列出原因：
  - 标尺缺失（倍率 / 像素标尺 / 微米值任一缺失）
  - 倍率与拼接图目标倍率不匹配
  - 相邻视野重叠不足（< 20%）
  - 坐标缺失、批内坐标重复
  - 坐标已归入其他拼接图（**同一坐标只能属于一个拼接图**）
  - 与原图方向冲突（**方向冲突不得覆盖原图**）
- **测量校准**：保存瞬间冻结标尺快照（µm/px），结果 = 像素长度 × 快照换算值；
  事后调整该视野的倍率或标尺，**已保存结果不变**，界面会提示当前标尺与快照的差异。
- **归档冻结**：归档后拼接结构、视野归属与测量全部只读；归档前再次强制完整校验
  （标尺、倍率、重叠链）。
- **复核另存**：对已归档拼接图发起复核时必须填写原因，系统把当时的拼接图、视野与测量
  深拷贝为旧版本快照单独留档，冻结原件不改动。
- **刷新一致**：所有数据自动写入 localStorage；界面临时状态（页签、表单、反馈）不持久化。

## 分层结构（数据 / 规则 / 界面分离）

```
src/
├── domain/            # 纯领域：类型与规则，无 React、无存储
│   ├── types.ts       # 玻片 / 视野 / 拼接图 / 测量 / 复核 数据模型
│   ├── rules.ts       # checkBatch 整批校验、标尺快照、冻结与复核等纯函数
│   └── format.ts      # 数字 / 时间展示辅助
├── data/              # 数据层：localStorage 读写与演示种子
│   ├── storage.ts
│   └── seed.ts
├── state/             # 编排层：纯 reducer + Context，规则通过才提交
│   ├── store.ts
│   └── AppProvider.tsx
└── components/        # 界面层：四个工作台页签
    ├── FieldRegistry.tsx   # 视野登记与台账
    ├── StitchWorkbench.tsx # 批量拼接 / 整批拒绝 / 草稿与归档
    ├── MeasureLab.tsx      # 标尺快照测量
    └── ArchivePanel.tsx    # 冻结视图与复核旧版本
```

演示数据内置了可直接试规则的场景：已归档的洋葱 400x 拼接图（含 v1 复核留档、
按旧快照保存的测量）、待归档的血涂片草稿，以及缺标尺、倍率不匹配、坐标冲突方向的视野。
点击「重置演示数据」可还原。
