# hxwl-06 视野拼接与测量校准台

由“显微镜玻片观察记录”扩展而来的视野拼接与测量校准台。

样本、多倍率视野、像素标尺登记、整批校验拼接、标尺快照测量、归档冻结与复核版本。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106。类型检查：`npx tsc --noEmit`；生产构建：`npm run build`。

## 分层（数据 / 规则 / 界面分离）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 数据 | `src/types.ts`、`src/store.ts`、`src/useBenchState.ts` | 领域模型、状态变更不变式、localStorage 持久化 |
| 规则 | `src/rules/calibration.ts`、`src/rules/stitching.ts` | 纯函数：标尺校准换算、拼接批次校验，不依赖界面 |
| 界面 | `src/App.tsx`、`src/components/*` | 四个标签页，只读/调用数据层与规则层，不内联业务判定 |

## 业务规则

1. **视野登记**：每个视野登记物镜倍率、像素标尺长度、标尺微米值；缺一不可测量、不可入拼接。
2. **整批拒绝**（任一触发即拒绝整批，并逐视野列出原因）：
   - 标尺缺失（像素标尺或微米值未登记/非正）；
   - 倍率不匹配（视野物镜与批次要求不一致）；
   - 相邻视野重叠不足（声明重叠率 < 10%）；
   - 坐标冲突：同一坐标只能归入一个拼接图（含跨拼接图互斥）；
   - 方向冲突：同一参考视野的同一侧被多个视野声明，不得覆盖原图像素；
   - 参考缺失、参考链成环、锚点缺失/不唯一。

   拒绝只在“拒绝留痕”中记录批次与逐视野原因，不产生任何拼接图，视野仍留在待拼接池。
3. **测量按标尺快照换算**：保存测量时接受当时的物镜、像素标尺、微米值与 µm/px 作为快照一并冻结；
   事后调整视野倍率或标尺，不回改、不重算已保存结果，列表标注“标尺已更新·结果不重算”。
4. **归档冻结**：active 拼接图可归档为 archived，拼接内容冻结。
5. **复核另存**：archived 只能通过“复核另存”派生新版本（versionNo 递增），必须填写原因；
   旧版本转为 history 原样保留，可在版本历史中查看旧版与复核原因。
6. **刷新一致**：所有状态经单一存储持久化，刷新后各标签页状态一致；“重置为示例数据”可还原种子。

## 界面流程

1. 视野登记：录入并查看每个视野的校准状态与 µm/px。
2. 视野拼接：选玻片/倍率/重叠率，加入视野并设置相对参考视野的方位；提交前实时预演规则，
   通过才可提交；失败显示整批拒绝原因与逐视野原因。
3. 测量校准：选择已校准视野，输入像素长度，接受快照并保存冻结结果。
4. 归档复核：归档冻结、查看版本历史、对归档版本复核另存新版本。
